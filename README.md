## Project Overview

This is my first mini-project focused on learning how to build a dynamic web application using core web technologies.

The project is a fully functional **Todo application** that allows users to add, view, and manage tasks dynamically. It helped me understand how user interactions, DOM manipulation, and basic application logic work together in a real-world web page.

## What I Learned
- Handling user input and events
- Dynamically updating the DOM using JavaScript
- Structuring a simple but functional web application
- Writing clean and readable client-side logic

This project marks an important step in my journey toward building interactive web applications.
